A catalog of useful software worth keeping for future reference.

| Program           | Link                                                        | Description                                                         | Why it stands out                                                    |

| Bun               | [bun.sh](https://bun.sh)                                    | Fast JavaScript runtime, package manager, and bundler.              | Combines several JavaScript tools in one executable.                 |
| fd                | [GitHub](https://github.com/sharkdp/fd)                     | Simple, fast alternative to `find` for locating files.              | Uses intuitive syntax and respects `.gitignore` by default.          |
